# Signal Construction Pipeline

An end-to-end AI system that converts a natural-language investment theme into a scored, tradable equity factor — backed by systematic literature research, live market data, and automated analytics.

Built by [Aaryan Goyal](https://github.com/aaryangoyal) and a co-founder as part of a broader quant research platform.

---

## What It Does

You type a theme: *"capture valuation reratings in indium phosphide photonics as AI datacenters hit bandwidth limits."*

The pipeline produces:

- A **mathematical framework** — signal taxonomy, composite weights, data requirements, universe definition
- An **executable DAG** — each node is a typed operation assigned to a specialized sub-agent
- **Live factor scores** — across a filtered equity universe pulled from real market data
- **Analytics** — Sharpe, max drawdown, Fama-French attribution, benchmark comparison, robustness checks

---

## Pipeline Architecture

```
Natural Language Theme
        │
        ▼
┌─────────────────────┐
│  Stage 1            │  Literature Agent
│  Framework Builder  │  Web search + schema generation → mathematical_framework.json
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  Stage 2            │  DAG Generator
│  DAG Compiler       │  Compiles framework into an executable directed acyclic graph
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  Stage 3            │  Orchestrator + 13 Sub-Agents
│  Factor Executor    │  Each DAG node dispatched to a typed agent with live data access
└─────────┬───────────┘
          │
          ▼
┌─────────────────────┐
│  Stage 4            │  Analytics Engine
│  Performance Layer  │  Holdings, returns, attribution, risk, robustness
└─────────────────────┘
```

---

## Sub-Agents (13 specialized agents)

The orchestrator dispatches each DAG node to a typed sub-agent. Agents are config-driven — capabilities, rate limits, and adapter access are defined in YAML registries, not hardcoded.

Agent types include: classification, scoring (LLM and rule-based), extraction (structured and LLM), web extraction, code generation, universe selection, aggregation, reshaping, event study, and output formatting.

---

## Data Adapters (13+ sources)

Live data is pulled through a typed adapter layer with defined contracts, validation, and rate limiting:

SEC EDGAR · Financial Modeling Prep · Polygon.io · News APIs · Patent databases · Open-source contribution signals · Consortia and grants · Company overviews · Inventory data · ID mapping
